# Contributing to Crowdwide

Thank you for your interest in contributing to **Crowdwide**! 🎉

Crowdwide is a community-first social platform focused on fair discovery, stronger communities, and giving new voices a chance to reach an audience.

Every contribution helps make the platform better.

## Ways You Can Contribute

There are many ways to contribute, including:

* 🐛 Reporting bugs
* 💡 Suggesting new features or improvements
* 🎨 Improving the UI/UX
* ⚡ Improving performance
* 🔐 Identifying and responsibly reporting security issues
* 📚 Improving documentation
* 🧪 Adding or improving tests
* 💻 Contributing code
* 🌍 Helping improve accessibility and user experience

## Before You Start

Before making a contribution:

1. Check the existing issues and pull requests to avoid duplicate work.
2. For major features or architectural changes, open an issue first to discuss the idea.
3. Make sure your changes fit Crowdwide's goal of improving communities and discovery.
4. Keep contributions focused and avoid unrelated changes in the same pull request.

## Getting Started

### 1. Fork the Repository

Fork the Crowdwide repository to your GitHub account.

### 2. Clone Your Fork

```bash
git clone https://github.com/DeveloperPuneet/Crowdwide.git
cd Crowdwide
```

### 3. Create a Branch

Create a separate branch for your changes:

```bash
git checkout -b feature/your-feature-name
```

For bug fixes:

```bash
git checkout -b fix/your-bug-name
```

### 4. Make Your Changes

Implement your changes while keeping the existing project structure and coding conventions in mind.

### 5. Test Your Changes

Before submitting a pull request, make sure your changes work as expected and do not introduce new problems.

Run the project's available tests and verify the affected functionality manually when appropriate.

### 6. Commit Your Changes

Use clear and meaningful commit messages:

```bash
git add .
git commit -m "Add community discovery improvements"
```

### 7. Push Your Branch

```bash
git push origin feature/your-feature-name
```

### 8. Open a Pull Request

Create a pull request against the main Crowdwide repository.

In your pull request, explain:

* What you changed
* Why you changed it
* How you tested it
* Any relevant issues or discussions

## Pull Request Guidelines

Please keep pull requests:

* **Focused** — solve one problem or introduce one clear improvement.
* **Readable** — keep the code understandable and maintainable.
* **Tested** — verify that your changes work before submitting.
* **Documented** — update documentation when necessary.
* **Respectful** — follow the project's Code of Conduct.

Large changes may be reviewed in smaller stages to make them easier to understand and maintain.

## Bug Reports

When reporting a bug, provide as much useful information as possible.

A good bug report should include:

* A clear title
* What happened
* What you expected to happen
* Steps to reproduce the issue
* Browser/device information when relevant
* Screenshots or logs when useful

Please avoid publicly posting sensitive information such as passwords, private user data, API keys, or authentication tokens.

## Feature Requests

We welcome ideas that improve Crowdwide.

When suggesting a feature, explain:

* What problem it solves
* How you think it could work
* Who would benefit from it
* Why it fits Crowdwide's goals

Features that improve discovery, community participation, accessibility, user experience, and fairness are especially relevant to the project's direction.

## Code Style

Please follow the existing coding style of the project.

In general:

* Use clear and descriptive names.
* Keep functions and components reasonably focused.
* Avoid unnecessary complexity.
* Remove unused code and imports.
* Add comments when they provide useful context, rather than explaining obvious code.
* Do not introduce unrelated formatting changes.

## Security

Please **do not publicly disclose security vulnerabilities through GitHub issues**.

Follow the instructions in [`SECURITY.md`](SECURITY.md) for reporting security vulnerabilities.

## Code of Conduct

Please treat other contributors and community members with respect.

Harassment, discrimination, personal attacks, and intentionally disruptive behavior are not welcome.

Contributors are expected to help maintain a friendly, constructive, and inclusive community.

## Questions

If you're unsure about something, feel free to open an issue or start a discussion before spending significant time implementing a change.

You do not need to be an expert to contribute.

Whether you're fixing a typo, improving the interface, reporting a bug, or building a major feature — **your contribution matters.** 🌍

Thank you for helping build Crowdwide.
